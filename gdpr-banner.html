🔒 Datenschutzerklärung — CyberCareer

1. Verantwortlicher

Diese Anwendung wird ausschließlich lokal auf Ihrem eigenen Gerät betrieben (localhost). Es gibt keinen externen Server oder Cloud-Dienst.

2. Welche Daten werden gespeichert?

  • Login-Token (im Browser-LocalStorage) — technisch notwendig für die Session
  • Benutzername & gehashtes Passwort (in storage.json auf Ihrem PC)
  • Bewerbungen (Titel, Unternehmen, Status) — nur lokal
  • CV-Text — wird nur während der Session im Arbeitsspeicher gehalten, nicht dauerhaft gespeichert

3. Keine Tracking-Cookies

Es werden keine Marketing-, Analyse- oder Tracking-Cookies verwendet. Google Analytics, Facebook Pixel oder ähnliche Dienste sind nicht eingebunden.

4. Externe API-Aufrufe

Die Anwendung ruft folgende externe APIs auf, wenn Sie nach Jobs suchen:

  • Bundesagentur für Arbeit (rest.arbeitsagentur.de) — öffentliche Stellenangebote
  • Arbeitnow (arbeitnow.com) — öffentliche API, keine Registrierung
  • Remotive (remotive.com) — Remote-Jobs, öffentliche API

Bei diesen Aufrufen wird Ihre IP-Adresse an die jeweiligen Server übermittelt (technisch unvermeidlich). Die Datenschutzerklärungen der jeweiligen Anbieter gelten entsprechend. Je nach Konfiguration können weitere Job-Quellen abgefragt werden (Adzuna, Jooble, LinkedIn — jeweils mit den genannten Übermittlungen).

4b. KI-Verarbeitung (Lebenslauf-Analyse, Anschreiben, Lernempfehlungen)

Wenn ein KI-Schlüssel in .env hinterlegt ist, wird der Text Ihres Lebenslaufs und ggf. die Stellenbeschreibung zur Verarbeitung an den ausgewählten KI-Anbieter übermittelt:

  • Google Gemini (generativelanguage.googleapis.com) — Standard in dieser Version
  • OpenRouter (openrouter.ai) — automatischer Fallback
  • Anthropic Claude / OpenAI — optional

Wichtig: Bei kostenlosen Tarifen (insbesondere dem Google-Gemini-Free-Tier) können die übermittelten Inhalte vom Anbieter zur Verbesserung seiner Modelle verwendet werden. Übermitteln Sie daher keine besonders sensiblen Daten. Ohne KI-Schlüssel arbeitet die App vollständig lokal (Vorlagen + regelbasierte Analyse); es werden dann keine Lebenslaufdaten an Dritte gesendet.

Bei aktivierter E-Mail-Benachrichtigung (RESEND_API_KEY) werden Ihre Empfänger-Adresse und die Job-Treffer zum Versand an Resend (resend.com) übermittelt.

5. Passwort-Sicherheit

Passwörter werden mit scrypt (Node.js built-in) gehasht und gesaltet gespeichert. Das Klartextpasswort wird zu keinem Zeitpunkt gespeichert.

6. Ihre Rechte (DSGVO / GDPR Art. 15–22)

  • Recht auf Auskunft — alle Daten liegen transparent in storage.json
  • Recht auf Löschung — löschen Sie einfach storage.json
  • Recht auf Datenübertragbarkeit — storage.json ist lesbares JSON
  • Recht auf Berichtigung — Passwort jederzeit änderbar

7. Datenlöschung

Um alle Ihre Daten vollständig zu löschen:

  • Löschen Sie storage.json im Projektordner
  • Leeren Sie den LocalStorage im Browser (F12 → Application → LocalStorage)

8. Rechtsgrundlage

Die Datenverarbeitung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. b DSGVO (Vertragserfüllung / berechtigtes Interesse) sowie Ihrer Einwilligung (Art. 6 Abs. 1 lit. a DSGVO).

Stand: Juni 2026 — Diese Erklärung gilt für die lokale Entwicklungsversion (Sprint 2, inkl. KI-Verarbeitung).
